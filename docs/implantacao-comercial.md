# Implantação comercial

Copie a base para cada estabelecimento, sem compartilhar dados privados. Edite menu-config.js: nome, itens com IDs inteiros únicos, categoria diferente de Todos, preço com até duas casas decimais, descrição e emoji. Mantenha demo: true até aprovação. Para pedidos reais, configure whatsapp com 55 + DDD + número, apenas dígitos, e demo: false. O usuário revisa e envia a mensagem no WhatsApp; não há confirmação automática, pagamento ou banco de dados. O carrinho guarda apenas IDs e quantidades no navegador, com chave derivada da configuração; alterações no catálogo podem reiniciar o carrinho. Não inclua segredos no código público. Valide preços e número com o cliente. Execute node --test tests/menu.test.cjs na raiz com Node 20+. Valide manualmente Safari, busca, carrinho, recarga e checkout em demo antes de publicar. Não altere main sem autorização. Os testes simulam DOM, não substituem navegador real.
